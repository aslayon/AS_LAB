# ETC

이 폴더는 프로젝트 본문에 넣기 애매한 요약 파일, 보조 문서, 범용 참고 자료를 모아 둡니다.

## 포함 대상

- 요약성 문서
- 포트폴리오용 설명 파일
- 프로젝트 간 공통 참고 자료
- 분류가 애매한 산출물

## 예시 파일

- `portfolio_click_detect.py`
- `portfolio_yolo_detection_summary.py`
- `portfolio_reinforcement_learning_summary.py`

## 안내

가능하면 개별 프로젝트 폴더 안의 `README.md`와 `docs/README.md`를 먼저 확인하고,
그 외에 남는 자료는 `misc/` 또는 이 폴더로 정리합니다.
