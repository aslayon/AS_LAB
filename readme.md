  (성공률: 73.3%)

  (평균 보상: 50.62)

  (평균 이동 스텝: 23.8)

* Best reward: **88.0**
  (최고 보상: 88.0)

The agent successfully learned obstacle avoidance behavior and demonstrated stable performance in randomized environments.
