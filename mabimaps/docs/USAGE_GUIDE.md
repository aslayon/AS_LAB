## 1. 사이트 소개

이 사이트는 지도(Leaflet)를 기반으로 다음 기능을 제공합니다.

- 지도에 표시된 **마커**(NPC/몬스터/이벤트/오브젝트 등) 확인
- **NPC / 아이템 검색**
- 마커 클릭 시 **판매/획득 아이템 목록** 확인
- 사용자 참여형 **데이터 제보**
  - 신규 마커 추가
  - 맵 이동 영역 추가(맵 간 이동 존)
  - 아이템 마스터 등록(아이템 이름/이미지)
  - 특정 위치(마커)에 아이템 정보 제보
  - 잘못된 아이템 정보 신고(🚨)

## 2. 기본 사용법(지도 탐색)

1. 사이트에 접속하면 지도 화면이 표시됩니다.
2. 지도는 마우스/터치로 이동 및 확대/축소가 가능합니다.
3. 마커를 클릭하면 상세 팝업이 열립니다.

![](assets/스크린샷%202026-03-18%20153732.png)

## 3. 검색 기능(NPC / 아이템)

좌측 상단의 검색창에서 **NPC 이름** 또는 **아이템 이름**으로 검색할 수 있습니다.

- 검색창: `NPC / 아이템 검색`
- 입력 시 자동으로 검색 결과가 하단에 리스트로 표시됩니다.
- 결과를 클릭하면 해당 위치(마커)로 포커싱됩니다.

표시되는 결과 메타 정보:

- `result_type`:
  - `marker` : NPC(마커) 이름 기반 결과
  - `item` : 아이템 이름 기반 결과(해당 아이템을 취급하는 마커)
- `area_id`: 결과가 속한 맵/지역 식별자(없는 경우 `위치 미상`)

> 스크린샷(선택):  
> `![검색 UI](assets/search-ui.png)`

## 5. 마커 팝업(아이템 목록/신고)

NPC 마커를 클릭하면 팝업에 다음 정보가 표시됩니다.

- NPC 이름
- NPC 이미지(없으면 기본 이미지로 대체)
- 설명(없으면 `세부 정보 없음`)
- **판매/획득 아이템 리스트**
  - 아이템 이미지, 아이템명
  - 가격(값 + 단위: 골드/두카트 등)
  - 획득 조건(있는 경우)

추가로 팝업에서:

- 우측 상단의 작은 버튼(🚨/이미지)로 **마커 신고** 및 **마커 이미지 재업로드**를 할 수 있습니다.
- **“이 위치에 정보 제보”**: 해당 마커에 대한 아이템 정보를 제보할 수 있습니다.

> 스크린샷(선택):  
> `![마커 팝업](assets/marker-popup.png)`

## 6. 데이터 제보 기능

우측 상단의 **“데이터 제보”** 버튼을 누르면 메뉴가 열립니다.

- 신규 마커 추가
- 맵 이동 영역 추가
- 아이템 마스터 등록
- 마커 위치 수정
- 모드 취소

> 주의: 제보 모드/편집 모드에서는 지도 클릭 동작이 바뀔 수 있습니다.

### 6.1 신규 마커 추가

1. `데이터 제보 → 신규 마커 추가`를 선택합니다.
2. 지도 커서가 십자 모양으로 바뀌면, 원하는 위치를 클릭합니다.
3. 팝업 폼에서 다음을 입력합니다.
   - 이름(필수)
   - 카테고리(필수): NPC/몬스터/이벤트/오브젝트/기타
   - 설명(선택)
   - 이미지(선택)
4. `제보하기`를 누르면 신규 마커가 등록됩니다.

> 스크린샷(선택):  
> `![신규 마커 제보 폼](assets/report-new-marker.png)`

### 6.2 맵 이동 영역 추가

이 기능은 **맵 내 특정 영역을 클릭/드래그**해서 다른 맵으로 이동하는 “존”을 추가할 때 사용합니다.

일반 흐름:

1. `데이터 제보 → 맵 이동 영역 추가`를 선택합니다.
2. 맵에서 이동 영역(bounds)을 지정합니다. *(프로젝트 설정에 따라 드래그 방식일 수 있습니다.)*
3. 팝업에서 다음을 입력합니다.
   - 이동할 맵 ID(필수)
   - 새로운 맵 이미지(선택)

중요 규칙:

- **새로운 맵을 추가**하려는 경우에는 보통 “새로운 맵 이미지” 업로드가 필요합니다.
- 서버는 이동 대상 맵(target)이 실제로 존재하는지 검사할 수 있습니다.

> 스크린샷(선택):  
> `![맵 이동 영역 추가 팝업](assets/report-new-zone.png)`

### 6.3 아이템 마스터 등록

아이템 이름(필수)과 아이템 이미지(선택)를 등록합니다.

1. `데이터 제보 → 아이템 마스터 등록` 선택
2. 아이템 이름 입력
3. 이미지가 있으면 업로드(선택)
4. `등록하기` 클릭

이미 등록된 아이템은 중복 등록이 거절될 수 있습니다.

> 스크린샷(선택):  
> `![아이템 마스터 등록](assets/item-master.png)`

### 6.4 아이템 이미지 수정

`데이터 제보 → 아이템 이미지 수정` 메뉴에서, 아이템 이름으로 **기존 아이템의 이미지**를 업데이트할 수 있습니다.

1. `데이터 제보 → 아이템 이미지 수정` 선택
2. 아이템 이름 입력(자동완성에서 **정확한 이름 선택 권장**)
3. “선택된 아이템: … (ID: …)” 형태로 바인딩 상태 확인
4. 새 이미지 파일 선택
5. `이미지 업데이트` 클릭

> 스크린샷(선택):  
> `![아이템 이미지 수정](assets/update-item-image.png)`

### 6.5 특정 위치에 아이템 정보 제보

NPC(또는 마커) 팝업에서 **“이 위치에 정보 제보”** 버튼을 누르면, 해당 마커에 아이템 정보를 제보할 수 있습니다.

입력 항목:

- 아이템 이름(필수, 자동완성 지원)
- 획득 방식: 상점/채집/드랍/기타
- 가격(선택): 가격 + 단위(골드/두카트 등)
- 추가 조건(선택): 예) 1랭크 이상
- 이미지(선택)

> 스크린샷(선택):  
> `![마커에 아이템 제보](assets/report-item-for-marker.png)`

### 6.6 잘못된 아이템 정보 신고(🚨)

마커 팝업의 아이템 리스트에서 🚨 버튼을 누르면 해당 아이템 소스를 “신고”할 수 있습니다.

- 신고가 접수되면, 화면에서 해당 항목이 제거될 수 있습니다.
- 누적 신고가 일정 기준을 넘으면(예: dislike_count 제한) 목록에서 노출되지 않을 수 있습니다.

> 스크린샷(선택):  
> `![아이템 신고 버튼](assets/dislike.png)`

마커 팝업 우측 상단의 🚨 버튼을 누르면 **마커 자체를 신고**할 수 있습니다.

## 7. 마커 위치 수정(편집 모드)

`데이터 제보 → 마커 위치 수정`을 선택하면 **편집 모드**가 켜집니다.

- 편집 모드에서는 마커를 드래그해서 위치를 수정할 수 있습니다.
- 편집 모드를 켜면 기존 제보 모드는 자동으로 해제됩니다.
- 다시 누르면 편집 모드가 종료됩니다.

> 스크린샷(선택):

## 8. 자주 묻는 질문(FAQ)

### Q1. 이미지가 깨져요 / 안 보여요
- 기본적으로 이미지가 없으면 기본 이미지로 대체됩니다.
- 업로드한 파일 확장자/경로가 올바른지 확인하세요.

### Q2. 검색 결과가 안 나와요
- 공백만 입력하면 검색되지 않습니다.
- 서버가 꺼져있거나, DB 연결이 안 된 경우 검색이 실패할 수 있습니다.

### Q3. “제보하기”를 눌렀는데 반응이 없어요
- 브라우저 콘솔(F12)에 에러가 있는지 확인하세요.
- 네트워크 탭에서 요청이 실패했는지 확인하세요.

## 9. 운영/개발자용: 실행 방법 & 환경설정

### 9.1 요구사항

- Python (권장: 3.10+)
- PostgreSQL(+ PostGIS 사용 가능 환경 권장)
- `requirements.txt` 설치

### 9.2 환경 변수(.env)

`.env.example`을 참고해서 `.env`를 구성합니다. (예: DB 접속 정보, PORT, CORS 등)

- `CORS_ALLOW_ORIGINS`  
  외부 도메인에서 프론트를 분리 호스팅하는 경우 허용 origin을 콤마로 설정합니다.  
  예: `CORS_ALLOW_ORIGINS=https://example.com,https://www.example.com`

### 9.3 실행

프로젝트 루트에서(예시):

```bash
pip install -r requirements.txt
python run.py
```

또는 FastAPI/uvicorn 직접 실행(개발용):

```bash
uvicorn main:app --reload
```

## 10. 문제 해결(트러블슈팅)

### 10.1 `/markers`는 뜨는데 아이템이 비어 있어요
- 해당 마커에 연결된 `item_sources` 데이터가 없을 수 있습니다.
- 팝업의 “이 위치에 정보 제보”로 데이터를 추가할 수 있습니다.

### 10.2 새로 만든 맵으로 이동이 안 돼요
- 맵 이동 영역 추가 시 `target map_id`가 실제로 `maps` 테이블에 존재해야 할 수 있습니다.
- 새 맵을 만드는 경우 이미지를 업로드하여 `/maps` 생성 플로우를 먼저 수행해야 합니다.

### 10.3 제보 업로드(이미지)가 실패해요
- 서버가 `static/images/...` 경로에 쓸 권한이 있는지 확인하세요.
- 업로드 파일이 너무 크거나(프록시/배포 환경 제한) 확장자가 제한될 수 있습니다.
