# 잡담 프롬프트 최소 수정 전후 비교

2026-10-21 (Asia/Seoul). 009 이후의 **프롬프트 동작 변경 + 문서 변경**. 구조·DB·의도 해석·이력 조립·검토·저장 흐름은 009와 동일하다. [최신 구조](../architecture.md), [변경 전 009 스냅샷](../architecture-history/009-free-input.md).

## 확인한 실제 입력 경로

`OllamaProvider.payload()`의 interaction.kind=conversation, focus 없음 경로를 확인했다. 실제 잡담 입력 8개 모두 이 경로로 해석됐다.

- 수정 전 도입 문장에서 “비 오는 밤의 기록 보관소”를 제시하고, 바로 뒤 persona.location에도 같은 장소를 넣었다. 장소 정보의 중복을 확인했다.
- “일반 대화의 주제를 이어가세요”는 짧은 인사·감사·동의에도 대화를 확장하도록 읽힐 여지가 있었다.
- dialogue를 “1~3문장”으로 요청했고 짧은 입력에 짧게 끝내거나 배경/질문의 필요성을 구분하는 지시는 없었다.
- 이 대사 생성 경로에는 별도 잡담 예시나 질문으로 끝내라는 지시는 없었다. intent의 날씨 분류 예시와 review의 시간 질문 예시는 별도 호출에만 있으며 잡담 초안 payload에 들어가지 않는다.
- `conversational_history()`는 실제 이전 잡담 답변을 다시 전달하므로 과거 반복 대사가 영향을 줄 가능성은 있다. 이번에는 이력 처리나 과거 대사를 변경하지 않았다. 비교는 첫 인사가 모델 이력에서 제외된 동일한 새 게임 상태, dialogue_history=[]로 했으며 장기 대화에서의 영향은 시험하지 않았다.

위는 코드에서 확인한 지시·정보이며 모델 내부 원인을 확정한 것은 아니다. 여러 지시를 한 번에 소폭 바꿨기 때문에 어느 문구 하나의 효과를 분리한 실험도 아니다.

## 최소 변경

수정 파일: `app/ollama_provider.py`, `payload()`의 일반 잡담 system 문자열만 변경했다.

- 장소가 중복된 도입을 캐릭터 이름 소개로 줄였다. persona.location은 유지했다.
- “일반 대화의 주제를 이어가세요”를 다음으로 바꿨다.

> 사용자의 말에 필요한 만큼 답하고, 짧은 인사·감사·동의에는 짧게 답하세요. 배경은 현재 발언과 관련 있을 때만 언급하고, 질문은 답변에 필요한 확인이 있을 때만 하세요.

- “대사 1~3문장”을 “대사”로 바꿨다. 기존 상태 판정/주장 구분/JSON 지시는 유지했다.

새 검증 로직·금칙어 목록·재시도·후처리는 추가하지 않았다. 의도/검토 프롬프트·선택식 행동·모델/온도/문맥 설정·state/config·화면은 바꾸지 않았다.

## 비교 방법

- 실제 로컬 모델 `qwen3:4b-instruct-2507-q4_K_M`, temperature=0.6, num_ctx=8192, num_predict=512, think=false.
- 수정 전에 실제 interpret()→ground_intent()→build_context()로 8개 입력의 맥락을 만들고 보존했다. 모두 conversation/speak/focus=null이었다. 수정 뒤에는 **보존된 같은 맥락**을 재사용했다. 초기 상태와 사용자 문장·이력·verdict·JSON Schema·생성 설정이 같다.
- 각 입력에 수정 전 1회, 수정 후 1회 propose()를 호출했다. 재생성·후보 선택 없이 얻은 dialogue 원문을 아래에 전부 적었다. 전후 합계 초안 16개다. 해석/검토 결과나 서버 대체문으로 초안을 바꾸지 않았다. 실제 화면의 최종 응답 비교와는 구분한다.
- 무작위 샘플링이고 seed를 고정하지 않았다. 한 쌍씩의 탐색 비교이므로 일관된 개선·통계적 유의성·장기 대화 품질을 보장하지 않는다.
- 사용자 DB·서버 프로세스는 조작하지 않았다. 일시적인 비교 스크립트는 `/tmp/character-chat-compare-smalltalk.py`, 전체 요청·출력·통계는 Git 제외 `.runtime/010-smalltalk-comparison.json`에 있다. 이 문서가 원문 보존본이다.

## 결과와 한계

**짧아진 표본은 있으나 개선은 불분명하다.** 한 차례 수정으로 종료하고 추가 장치를 붙이지 않았다.

- 평균 글자 수(공백·문장부호 포함)는 65.75→48.25자다. 8개 중 6개는 짧아졌고, “잠깐 쉬고 싶어요.”와 “비가 많이 오네요.”는 오히려 길어졌다. 길이 감소 자체가 품질 개선은 아니다.
- 사람이 원문을 읽어 비/밤/보관소 배경 언급을 세면 8/8→6/8이다. 날씨 관련 입력 한 건을 제외한 7개에서도 7→5건에 배경이 붙었다. 수정 후 두 인사 모두 여전히 배경을 덧붙여 요구를 충분히 만족하지 못했다.
- 물음표가 포함된 응답은 4/8→4/8이다. 수정 후 “조금만 더 기다려 주실 수 있나요?”, “잘 지내시나요?”, “잘 쉬었나요?”, “잠깐 쉬는 거요?”는 현재 발언에 꼭 필요한 확인으로 보기 어렵다. 불필요한 질문 감소는 확인하지 못했다.
- 수정 후 “안녕히 하시죠” 같은 어색한 표현이 남았다. 감사에 “기록을 잘 보관해 주셔서 감사합니다”, 날씨에 “어제는 비가 그만큼 강했어요” 같은 근거 없는 내용을 덧붙였다. 이번 요청은 잡담 스타일 프롬프트 수정이므로 추가 사실 검증이나 대체 장치를 도입하지 않고 품질 한계로 기록한다.
- 새 게임·이력 없는 8개에 한정된 결과다. 이전 배경 대사가 쌓인 실제 분기나 같은 입력 재실행에서는 다른 결과가 나올 수 있다. 기존 저장 대사를 수정하지 않았으며 말투 개선을 보장하지 않는다.
