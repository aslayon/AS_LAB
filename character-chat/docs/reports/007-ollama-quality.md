# 007 · 실제 Ollama 연속 대화 품질 검토

확인일: 2026-10-21 (Asia/Seoul). 자동 상태 검증과 아래 **사람이 원문을 읽고 판단한 대사 품질**은 별개다. 자동 의미 평가기나 품질 보증을 구현한 것이 아니다.

## 실행 환경과 범위

- 모델: `qwen3:4b-instruct-2507-q4_K_M`, Ollama 0.40.6. 모델 교체·다운로드·드라이버·시스템 설정 변경 없음.
- 선택식 공개 기록 경로·열람 전 회귀·신분증 주장과 봉인 허가 요구·강제 접근 반복을 정상·신분·강제 접근 세 경로와 회귀 분기에서 확인했다. 플레이 DB 대신 임시 SQLite를 사용했다.
- `.venv/bin/python -m scripts.verify_ollama`가 상태·저장·미래 문맥 격리를 검사하며, 대사 품질은 `pending_human_review`로 남긴다. 아래 평가가 그 별도 수동 검토 결과다.
- 요청별 전체 입력·원본 출력·진단 산출물은 Git 제외 `.runtime/ollama-validation.json`에 있다. 이 문서는 합성 테스트 대화만 보존하며 사용자 플레이 DB를 복사하지 않는다.

## 최종 결과

**자동 상태·저장 검증은 11사례 통과. 대사 품질은 부분 통과.** 정상 목록·선택·열람은 화면의 서버 결과와 고정 본문으로 끝까지 진행할 수 있다. 원본 실패 사례의 가짜 신분증 검증·허가 완료 주장은 이번 최종 표본에서 나오지 않았다. 그러나 신분 질문을 회피하는 반복, 원문 시간 정보의 변형, 종료 범위 과장 등이 남았다. 모든 대사의 사실성이 해결됐다고 보고하지 않는다.

회귀 후에는 선택 상태만 남고 열람 이력은 비었으며, 이후 모델 입력의 사건·요약·기억과 본문에 미래 열람 정보가 없었다. 선택 분기의 원본은 그대로 보존됐다. 이력에 있는 다른 완료 대사를 자동 재생해서 상태를 복구하지 않는다.

응답 시간 **0.55–1.26초, 중앙값 0.93초**. 이미 로딩된 모델 표본이다. `/api/ps`의 size와 size_vram은 모두 **3,877,571,133 bytes**, 문맥은 8192로 GPU 적재를 확인했다. 순간 GPU 이용률 100%를 의미하지 않는다.

## 중간 실패와 수정 근거

첫 11사례에서는 상태만 맞고 모델은 거의 모두 첫 인사를 복사했다. 이를 품질 통과로 세지 않았다. 저장된 요청 3개에서 결과를 마지막 system/user 작업으로 전달하거나 이력을 뺀 조건을 9회 비교했다. 이력을 빼면 일부 결과 안내가 좋아졌지만 대화 기억을 버리는 변경은 채택하지 않았다. 대신 이력을 장면 JSON 자료로 유지한 6사례 비교에서 목록·열람 설명이 구체화되는 것을 관찰했다. 작은 비교 표본이므로 모든 입력의 개선을 증명한 것은 아니다.

이후 판정 전 상태 대신 결과를 적용한 예상 상태를 전달하고, 실제 가능한 다음 행동을 계산했다. 특히 종료 상태에서도 모든 행동을 가능하다고 전달하던 모순을 제거했다. 과거 모델 대사를 확정 결과로 재사용하지 않도록 서버 결과 기반 이력을 적용하고, 이번 결과와 다음 진행을 마지막 장면 작업으로 분리했다. 중간 시험에는 여전히 종료를 미래 경고로 말하거나 신분증을 제시하라고 하는 실패가 있었으며 최종 표본과 구분한다.

일부 문장이 좋아졌다고 모델 내부의 반복 원인 하나를 증명한 것은 아니다. 모델·샘플링을 바꾸거나 문자열 유사도 차단·자동 재시도·단어 금지 필터를 추가하지 않았다.

## 자동 테스트가 보장하는 범위

Python **75개 통과**, Starlette/httpx deprecation 경고 1개. 두 Node DOM 대역 검증도 통과했다. 실제 사용자 브라우저의 레이아웃 검증은 아니다. 검증에는 3개 기록의 끝까지 진행, 선행 조건·잘못된 ID·발언의 상태 불변, 예상 열람 상태의 생성 실패 시 무저장, 열람 전 회귀·미래 문맥 격리, 개발 trace 기본 비공개·무저장, 원본 실패 입력 재생이 포함된다.

고의로 “허가 발급 완료”라고 말하는 스키마 유효 모델을 넣은 테스트도 있다. 이 테스트는 **대사의 거짓말을 탐지·거부했다는 뜻이 아니다.** 봉인은 유지되고, 서버 확정 문장은 거절이며, 요약·기억·다음 모델용 확정 이력에 가짜 허가가 들어가지 않는지를 검증한다. 이 경우 거짓 대사는 화면에 표시될 수 있다. 모든 자연어 모순을 자동 차단하는 기능은 미구현이다.
