# 원인 분리: 일반 채팅 A와 실제 게임 요청 B

2026-10-21 (Asia/Seoul). 실행 시 코드: 9810090. **실험 도구·문서 변경 / 게임 동작 변경 없음.** 프로덕션 소스 해시가 실험 전후 동일했다. 실험은 30개 생성이 완료됐으며, 이후 사용자가 더 큰/한국어 모델 비교로 방향을 조정했다. 프롬프트를 추가 보강하지 않았다.

## 조건

각각 동일한 질문 5개를 3회, **A 15개 + B 15개** 생성했다. 입력은 인사·늦은 업무·장소 소개·비 피하기·안쪽 공간 질문이다. 각 질문은 새 게임/빈 대화 맥락에서 독립 실행했다. 회차별 A/B 선행 순서를 교대했으며 중간 프롬프트 수정·재시도·후보 선택·추가 검토는 없었다.

모델은 qwen3:4b-instruct-2507-q4_K_M(Q4_K_M), Ollama 0.40.6. 초안 temperature=0.6, num_ctx=8192, num_predict=512, think=false, stream=false, keep_alive=5m. 요청에서 seed를 지정하지 않았다. 원래 태그의 top_k=20/top_p=0.8/repeat_penalty=1을 양쪽 모두 그대로 사용했다.

| 조건 | A 일반 채팅 | B 실제 게임 |
| --- | --- | --- |
| system | 아래 짧은 캐릭터 설명 | 현행 payload()의 캐릭터 자료·관찰·관계·지침·verdict |
| user | 질문 원문 | 같은 질문 원문. 실제 free API가 의도를 판정한 경로 |

A 설명:

> 당신은 골목 안의 잘 알려지지 않은 기록 보관소에서 일하는 서린입니다. 신중하고 원칙적인 보관인으로, 비가 내리는 늦은 밤에 장부를 정리하고 있습니다. 접견 공간에서는 잠시 비를 피할 수 있고 안쪽에는 기록 보관용 서가가 있습니다. 한국어로 방문자와 대화하세요.

A/B는 동일 모델·초안 생성 설정이지만, **system 길이·자료 구조·출력 형식·의도/검토 유무가 동시에 다르다.** 어느 요소 하나의 효과를 분리한 실험이 아니며 JSON Schema만 원인이라고 결론 낼 수 없다. A의 모든 문장과 B의 JSON dialogue를 비교했다. B의 JSON 바깥 구조를 한국어 문법 평가에 넣지 않았다.

## 원문·최종 보존

[전체 30개 원문·최종 대사·실제 요청·응답 JSON](dialogue-ab-samples.json)에 보존했다. 각 항목에 arm/repetition/input/raw_dialogue/final_dialogue/review가 있다. A 최종은 미검토 원문과 같다. B도 **15/15에서 원문=최종**이었다. B 기존 검토는 전부 consistent=true였다. 따라서 이번 표본의 어색한 문장은 기존 대체 후처리 때문에 생긴 것이 아니다. 그렇다고 모든 과거 턴에 대해서까지 일반화하지 않는다.

30건 모두 HTTP 성공, length 종료는 없었다. B 15건의 관계/사건/진행/종료/기억도 불변이었다. 모델이 없던 행동을 말하는 문제와 실제 서버 상태 변경은 별개다. 개인 플레이 DB·사용자 프로세스는 건드리지 않았다.

## 사람이 읽은 비교

아래는 추가 모델 평가 없이 원문을 읽은 판단이다. “문법”에는 엄격한 조사/주어 결합 오류와 어색한 표현을 구분해 적었다. 설정에 없는 장소/날씨 창작은 별도 사실 문제이며, 제안이나 질문을 이미 완료된 행동으로 세지 않았다.

| 기준 | A 일반 채팅 | B 게임 원본/최종 |
| --- | --- | --- |
| 문법·한국어 표현 | “아무도 안 들어오지 않기 때문에”의 부적절한 이중 부정(A 2회 장소), “어떤 기록을 찾아보려고 계신가요?”(A 1회 업무), “그걸 보는 자리를 내려야”(A 2회 안쪽) 등 기본적인 결합·의미 문제가 있음 | 대체로 짧지만 “방문자들의 접견과 기록”(B 3회 장소) 같은 어색한 명사 결합, “그래, …생겼습니다”(B 3회 업무)의 말투 혼용, 인사에 “기다려도 되겠어요?”(B 2회)의 화자 혼동이 있음 |
| 질문 관련성 | 초반에는 답하지만 이어서 날씨·방문 목적·기록 찾기로 자주 벗어남. 비 피하기 응답에 외출 금지·기록 찾기·시간 보내 달라는 요청까지 확장 | 장소·비 피하기는 더 직접적. 업무 질문에는 비나 조용히 지내는 이유로 벗어나는 사례가 남음 |
| 없는 행동 생성 | A 2회 안쪽에서 “비가 내린 날 누군가 흩어진 편지들을 찾았던 이야기”라는 미제공 과거 사건을 창작. 기록 종류/역사/현재 햇빛 등 다른 설정 창작도 별도로 발생 | B 2회 업무의 “방금 들어왔습니다”는 주어 자신의 미제공 행동 완료를 생성. 안쪽을 비 피하는 공간으로 설명한 B 1회는 위치 사실 혼동. 입장 제안 자체는 행동 완료와 구분 |
| 불필요한 반복 | 인사도 긴 소개로 확장하고 비/보관소/도움 질문을 반복. 대다수 응답에서 후속 질문이 여러 개 붙음 | 길이는 줄지만 인사 3회 모두 날씨+후속 질문을 덧붙임. 업무 답변도 세 번 모두 비를 끌어옴 |

글자 수(공백 포함) 평균은 **A 246.47자 / B 47.27자**다. A 131–397자, B 30–73자였다. 길이 차이는 출력 형식·지침 차이의 영향을 함께 받으며, 짧다는 이유로 B가 적절하다고 판정하지 않는다.

A의 늦은 밤 설정에 “햇빛이 조금씩 보이기 시작”을 덧붙이거나, 안쪽에 1940–1970년대 지도/사진이 있다고 말한 것은 **미제공 설정 창작**이다. 대사의 창의적인 비유와 확인된 세계 사실을 혼동하지 않는다.

## 결론과 한계

**A에서도 품질이 부족했다. 게임 요청만을 유일한 원인으로 볼 수 없고 현재 모델 또는 실행 설정의 한계 가능성이 남는다.** B는 일부 길이·직접성이 나았지만 기본적인 한국어/관련성/사실 문제가 남았다. 이후 프롬프트·금칙어·재시도·검토를 덧붙이지 않았다.

이 실험만으로 모델 크기, 학습 데이터, 양자화, 채팅 템플릿, 샘플링 설정 중 무엇이 원인인지 확정하지 않는다. 생성 예산도 모두 length 종료가 아니어서 단순 토큰 잘림만으로 설명할 수 없다. 정량 점수의 신뢰구간이나 외부 평가자는 없으며, 짧은 5개 입력의 탐색 비교다. 새로운 후보 비교는 동일한 짧은 설정·일반 텍스트 출력으로 진행해 게임 구조와 분리한다.

기존 기능 테스트는 프로덕션 변경이 없어 재실행하지 않았다. 구조는 010과 같아 스냅샷을 추가하지 않았다. 원본 작업 도구는 scripts/compare_dialogue_ab.py이며 기존 결과를 덮어쓰지 않는다.
