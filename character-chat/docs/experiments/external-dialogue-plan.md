## 작은 실험과 비용 가정

[오프라인 입력·요청 계획 JSON](external-dialogue-plan.json)은 기존 scripts/compare_models.py의 DESCRIPTION/QUESTIONS/CONVERSATION을 그대로 가져왔다.

- 독립 질문 5개 × 3회 = 15회.
- 동일한 사용자 발언의 4턴 연속 대화 × 1회 = 4회.
- 합계 **19회**, 각각 일반 텍스트 대사 생성만. 출력 상한은 요청당 512토큰.
- 이전 외부 응답을 후속 연속 대화에 그대로 넣는다. 이전 로컬 assistant 출력을 새 모델에 주입하지 않는다.
- 재시도·좋은 답변 선택·검토 모델·JSON Schema·의도 해석·게임 연결은 하지 않는다. 실패/잘림도 원문으로 남긴다.

토큰 수는 아직 해당 API로 세지 않은 추정이다. 짧은 설명·질문·연속 이력 재전송까지 합쳐 입력 6,000–12,000토큰, 출력 2,000–5,000토큰을 가정하면:

- 낮은 쪽: 6,000 × $2/1M + 2,000 × $10/1M = **$0.032**.
- 높은 쪽: 12,000 × $2/1M + 5,000 × $10/1M = **$0.074**.
- 안내 예상액은 **약 $0.03–0.08**, 사용자 확인을 요청할 보수적 실험 예산은 **$0.20(세금·환전 제외)**다.

19회가 모두 출력 상한에 닿으면 출력만 9,728토큰, $0.09728다. 입력 합계 20,000토큰 가정까지 더하면 $0.13728다. 이는 가정별 계산이지 계정의 자동 결제 상한 보장이 아니다. 승인 후 실행 도구에서는 사용량·누적 비용을 기록하고 다음 요청의 예상 상한이 승인 예산을 넘으면 보내지 않도록 한다. API 충전/계정 결제와 이번 실험에서 소모하는 토큰 비용은 구분한다. 현재는 결제·충전·API 키 확인·유료 요청을 하지 않았다.

## 로컬 실험과 다른 조건

설명·질문·텍스트 출력·512 출력 상한은 재사용하지만 API/토크나이저·채팅 템플릿·하드웨어가 다르다. 특히 Sonnet 5.5는 temperature/top_p/top_k의 non-default 값을 지원하지 않아 로컬의 0.6/0.8/20을 복제하지 않는다. 해당 필드를 생략하고 차이를 결과에 명시한다.

사전 사고 출력을 끄는 공식 `thinking: {"type":"between_tools"}`와 `output_config.effort="medium"`을 제안한다. 도구를 사용하지 않으므로 공식 문서상 응답은 텍스트만이다. [공식 옵션 설명](https://platform.claude.com/docs/en/models/sonnet-5-5/whats-new-sonnet-5-5). 실제 계정/모델 지원 확인도 승인 이후에 하며 오류가 나면 중단·보고하고 다른 모델로 자동 전환하지 않는다. 모델별 형식 차이는 실험 호출 옵션으로만 다루고 프로덕션 예외 처리로 넣지 않는다.

## 평가와 중요한 구분

1. 자연스러운 한국어: 조사·주어/서술어·단어 선택·높임말·발화자 역할·읽기 쉬운 문장.
2. 질문에 직접 답하는가: 답을 먼저 하는지, 묻지 않은 절차나 배경으로 흐르는지, 불필요한 후속 질문·반복이 있는지.
3. 중요한 사실을 임의로 확정하는가: 사용자 행동 완료, 봉인 열람 허가, 기록 획득·열람 완료, 관계/사건 결과 등을 근거 없이 확정하는지.

가벼운 묘사·제안과 확정 사건을 구분한다. 예를 들어 보관인의 고개 끄덕임이나 빗소리 묘사, “잠시 쉬세요”, “차를 드릴까요?”는 그 자체로 열람/아이템 획득 성공이 아니다. 반대로 “당신은 봉인을 열었습니다”, “허가를 발급했습니다”, “기록을 손에 넣었습니다”는 중요한 결과의 확정이다. 제안이 설정과 충돌하면 설정 문제로 별도 표시하되 행동 완료와 혼동하지 않는다. 기존 로컬 보고의 모든 미제공 묘사를 중대한 사건 생성으로 일괄 취급하지 않는다.

이 기준은 실험 평가표이며 새 금칙어/서버 검증기/모델 지시로 추가하는 것이 아니다. 원문을 읽고 근거를 남기며 자동 모델 채점은 하지 않는다.

## 출력 확인과 이후 단계

- API 요청 조건·원본 응답 전체·실제 token usage·단일 호출 소요 시간·비용을 보존한다. 원문을 다듬거나 서버 문장으로 대체하지 않는다. 이번에는 검토 전후 처리가 없으므로 평가할 대사는 원본 그대로다.
- 사용자에게 **19개 출력 원문을 먼저 제공**하고 확인을 기다린다.
- 이후 사용자가 진행을 확인한 경우에만 의도 해석·기존 게임 연결을 검증한다. 이번 비용 제안은 그 후속 단계의 호출을 포함하지 않는다.
- 현재는 계획만 작성했으며, 유료 실행 도구/외부 provider/프로덕션 코드/모델 기본값은 추가·변경하지 않았다. 구조가 같아 010 스냅샷을 유지하고 새 스냅샷은 만들지 않는다. 기능 테스트도 재실행하지 않았다.
